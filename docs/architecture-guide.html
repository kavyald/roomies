Where it stands

Roomies is a phone-first web app (installable to the Home Screen) for one house of 2–8 roommates. It tracks needs (things to buy), chores, and tasks, plus polls and runs (a shopping trip, a request to the landlord, a planned visit). Roommates attach feelings to items, and feelings push items up the Home feed.

Pick a journey

Start with “Save a change” to see the write path, the core of the design: the browser never writes to tables directly.

    LinkWhat travels
    Phone → proxy → server actionsEvery write, as a Next server action (POST). No table writes from the browser.
    Phone ↔ Postgres (left rail)Reads through PostgREST with the user's JWT (RLS applies), and Realtime messages back.
    Adapters → PostgresKysely SQL as app_server, switching to authenticated + JWT claims per transaction.
    pg_cron → cron routespg_net POSTs /api/cron/<job> with x-cron-secret; URL and secret come from Supabase Vault.
    Adapters → Web Push → service workerVAPID-signed pushes via web-push; the service worker shows them.
    Auth → Gmail → you6-digit sign-in codes via custom SMTP (Mailpit locally until E1).

    Zoom in: the code layers

    Ports and adapters with dependency injection (decision A10). Dependencies only point inward, and a lint rule (eslint-plugin-boundaries) plus lib/architecture.test.ts enforce it. Open a layer, then a module, to see its functions.

    Backend decisions

    Chosen for one house, one developer, and free tiers: few vendors, one language, and the database as the last line of defense for privacy.

    Runs: three kinds, one machine

    A run is anything that works through several items at once. Items point at their current run; where they've been is read back from activity.

    Batch · “Kavya's grocery run”

    open→finishedoptional “Spent” on Finish

    Request · tasks for the landlord

    gathering→sent→closedauto-closes when emptied

    Visit · the landlord has taken them on

    open (date optional)→finished

    Recording a reply is just moving tasks: to a visit, back to the pool with a note, hand to another contact, or done. No reply form (D22).
